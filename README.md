# Linux Security Lab 🐧🔐

A structured Linux cybersecurity learning and analysis project focused on **Linux security, authentication, permissions, SSH, log analysis, privilege management, and system hardening**.

This repository is designed from a **SOC / Blue Team defensive-security perspective** and documents security concepts, investigations, and practical analysis workflows.

---

## 🎯 Project Objectives

* Build practical Linux security knowledge.
* Understand Linux users, groups, and permissions.
* Analyze authentication and security logs.
* Understand SSH security and common risks.
* Investigate suspicious authentication activity.
* Understand privilege escalation risks.
* Apply Linux security-hardening principles.
* Develop SOC-style investigation and documentation skills.

## 🕵️ Security Investigations

### SSH Authentication Investigation

A simulated investigation analyzing failed SSH authentication attempts followed by successful authentication.

Focus areas:

* Authentication events
* Timeline construction
* Suspicious behavior
* Risk assessment
* Defensive recommendations

### Privilege Escalation Investigation

A simulated investigation focused on suspicious `sudo` activity and potential unauthorized administrative access.

Focus areas:

* Failed privilege attempts
* Successful privilege escalation
* Administrative activity
* Investigation questions
* Defensive controls

> **Note:** The investigations in this repository are educational simulations unless explicitly identified as hands-on lab evidence.
