# 🐧 Linux Security Lab

Hands-on cybersecurity learning project focused on Linux system administration, security fundamentals, authentication, permissions, SSH security, system services, and security log analysis.

## 🎯 Objectives

This project is designed to develop practical skills in:

* Linux security fundamentals
* User and group management
* File and directory permissions
* SSH security
* Authentication and access control
* Linux services
* Security log analysis
* Basic security investigation
* Security hardening

## 🔐 Security Topics

### 1. Linux Users & Groups

Understanding users, groups, privileges, and account management.

### 2. File Permissions

Learning Linux ownership and permissions:

* Read
* Write
* Execute
* User
* Group
* Others

### 3. SSH Security

Studying secure remote access and common SSH security risks.

### 4. Authentication Logs

Learning how authentication events can be investigated through Linux logs.

### 5. Security Investigation

Analyzing authentication activity to identify suspicious or unsuccessful login attempts.

### 6. Basic Hardening

Documenting security recommendations such as:

* Strong authentication
* Least privilege
* Secure SSH configuration
* Regular updates
* Account monitoring
* Log monitoring
